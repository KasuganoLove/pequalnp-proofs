## 精确语义

输入0..4为行，输入5..9为列；只在`oneEach u v`上检查。目标位序是`5*u+v`，矩阵是：

```
01111
10001
00001
11100
11100
```

`gates`的条目为`[op,a,b]`，`op=0`表示AND，`op=1`表示OR；第i个门的输出wire为10+i。门只读早先的wire，输出索引另列。搜索允许一般共享和嵌套，没有固定前两个门必须合并相同的行或列。

初始池包含root给出的已验证11门电路的全部22个单门旁路，以及另一个13门行列分解的13,728个三次旁路，共13,750条。所有种子都只有10门。随机种子固定为921920261125。

## 复现

需要C++17编译器和Python3。在本目录运行：

```bash
python3 prepare.py
g++ -O3 -std=c++17 -o search10 search10.cpp
bash -c 'ulimit -v 262144; time ./search10 300' > bounded-run.log 2>&1
python3 verify.py best-10.json
```

`prepare.py`已实际执行，两个基线均通过25行断言；生成的seeds、rows和problem与本次搜索输入逐字节一致，见`prepare-verification.json`。`verify.py`不复用位并行评价器，而是逐门、逐行进行布尔求值。搜索程序检查本目录`STOP`文件并处理SIGTERM/SIGINT。

实际搜索的内部时长300秒，shell墙钟300.016秒，用户CPU299.496秒；虚拟内存限制由shell设置，未另测峰值RSS。未启动第二次搜索。

## 尚未形式化的结构观察

每一个行输入都必要：若电路不读某行u，某个`A(u,v)=1`将迫使仅列v为真时输出也为真；由单调性，同列的所有其他行就都必须为真。然而本矩阵每行都含有一个并非全列通用的1。列输入同理。因此全部10个raw inputs都必须使用。

在正确完成常量传播、去掉无用门并规范成严格二输入后，至多10门且使用全部10输入的电路最多只有一个fanout剩余单位。这提示一个有限分类：一个共享的子树（也可能只是raw input）被使用两次，其余部分为无共享公式。完整枚举必须同时覆盖共享叶子、共享复合子树，以及所有AND/OR结构；仅预先合并相同行列不足以构成完备证明。没有实现或运行这个分类枚举，也没有把观察当作10门不可能的证明。
