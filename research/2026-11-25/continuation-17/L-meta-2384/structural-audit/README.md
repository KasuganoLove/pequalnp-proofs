```

```

故 `size≤21`、`u≤r` 时有 `t+(r−u)≤6`。原图覆盖数为 7；若能构造题面所要的 K、X，便有 `|K∪X|≤t+(r−u)≤6`，与覆盖数矛盾。因此所缺的扩张计费确实承载了电路下界，不能仅凭图的覆盖分类填补。

## 3. 候选最大 junk 计数：UNFORMALIZED

以下是纸面论证，**没有 Lean 声明、kernel 验证或官方接受**，也不宣称全库中不存在同类引理。

在同样的有限、严格二输入 AND/OR 最小电路中，令 M 为所有在 junk 偏序中极大的门：`d∈M` 当且仅当 `d∈junk`，且没有另一个 junk 门的严格输入锥包含 d。候选关系是

```
|M| ≤ 2|centreless| + |orN\lam| = 2c+o.
```

该论证需要所有门都有通向输出的路径。对题面的 IsLeastAO，预期由删去无读者门的最小性论证得到；L1491 的 `S98.least_read` 与输出末门引理提供现成起点，但这里没有完成 API 连接。

**路径终点。** 从每个 d∈M 选一条通向输出的前向路径。d 的输出没有 OR-only raw-input 支持。沿路径，只要尚未遇到 AND，信号经 OR 传播，因此 d 的某个 graph-negative 真值见证仍会使这些 OR 为真；这些 OR 都是 dirty。停止于下列第一处：

1. OR 输出首次有非空 `orIn`。沿途输入的 `orIn` 为空，另一个输入非空，所以这是一个 mixing 门，其 empty 输入是一处出口。
2. 首次遇到 AND，且此前仍是空 `orIn`。该 AND 不能是另一 junk，否则违背 d 的极大性；它是 clean top，且该输入为空，所以是 centreless top 的一处输入端口。

若一直没有上述出口而到达输出，纯 OR 传播会使输出在 d 的负见证上为真，与输出正确计算 F 矛盾。因此选定路径确实终止。这里没有把任意 dirty AND 的读者擅自当作 clean；极大性是关键。

**共享 DAG 的全局计数。** 令 E 为所有这些截断路径上、出口之前的 OR 门的并集；它们的输出 `orIn` 为空，且均 dirty。令 Z 为出口处的空支持输入线的集合。每个 mixing 门至多贡献一个这样的线，每个 centreless top 至多贡献两个，所以 `|Z|≤|mixing|+2c`。

把门 d 的输出线 `n+d` 计作节点，则 M 的输出与 E 的输出互不相交。每个这些输出线，要么在 Z 中，要么作为某个 E 门的输入出现。因此

```
|M|+|E| ≤ |Z| + |⋃e∈E inputs(e)| ≤ |Z|+2|E|,
|M| ≤ |Z|+|E| ≤ 2c+|mixing|+|E| ≤ 2c+o.
```

最后一步使用：E 与 mixing 互不相交，并且都包含在 `orN\lam` 中；lam 要求两个输入均有非空 `orIn`。**这里对所有路径的并集计数，不把每个 cone 的门数分别相加**，所以共享子电路和多重扇出没有被重复收费。L1491 的 `cone_count2` 是单根锥的相关工具，但直接逐根相加不足以证明这个全局关系。

**若形式化成功，它能排除什么？** 若所有 junk 互不嵌套，则 M=junk，故 `j≤2c+o`、`2j≤r<2u`，从而 `j+1≤u`。这只会排除“独立双 junk 且 u≤2”以及“至少三个、全部互不嵌套的 junk 且 u≤3”等小情形。两个嵌套 junk 的 M 只有一个，这个关系只给出 `1≤2c+o`；它不解决 L5230。它也不解决 independent/shared-top 的 `u≥3` 或一般的多 junk 分支。此候选不被当作完整 2384 证明。
