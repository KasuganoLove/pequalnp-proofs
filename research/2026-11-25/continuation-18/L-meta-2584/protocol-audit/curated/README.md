## 已有结果没有自动补上 Read2 归一化

`ReadK.IsReadK n C 2` 要求每个素蕴含项有**同一棵证明树**同时把每个变量读取次数限制到2。它不是门的扇出上限，也不是逐变量各选一棵树，更不是只要求某一侧读一次的 `IsSingleRead`。
